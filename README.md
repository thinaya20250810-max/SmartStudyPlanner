# Smart Study Planner

A full-stack web application designed to help university students
organize their subjects, assignments, deadlines and study sessions.

## Project Overview

Smart Study Planner helps students manage their academic workload
and organize their study time through a centralized dashboard.

## Main Features

- User authentication
- Subject management
- Assignment management
- Deadline tracking
- Study session planning
- Calendar
- Progress tracking
- Dashboard statistics
- Smart study recommendations

## Technologies

- HTML
- CSS
- JavaScript
- Java
- Spring Boot
- MySQL
- Git
- GitHub
